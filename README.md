# Financial Tracker Application

Aplikasi manajemen keuangan pribadi berbasis Full-Stack Web yang dirancang untuk membantu pengguna mencatat dan memantau arus kas harian secara real-time.

---

## Fitur Utama

- **Autentikasi Pengguna**: Sistem Login & Register aman menggunakan JSON Web Token (JWT) dan enkripsi password `bcrypt`.
- **Manajemen Transaksi (CRUD)**: Menambah, melihat, mengedit, dan menghapus data transaksi pemasukan/pengeluaran.
- **Kalkulasi Otomatis**: Ringkasan Total Pemasukan, Total Pengeluaran, dan Sisa Saldo ter-update secara otomatis.
- **Filtering & Pencarian**: Filter transaksi berdasarkan Tipe (Income/Expense), Kategori, dan Tanggal.
- **Antarmuka Responsive & Clean**: Desain modern menggunakan React.js dan Lucide Icons.

---

## Tech Stack

- **Frontend**: React.js, Vite, Lucide React, Axios
- **Backend**: Node.js, Express.js
- **Database**: PostgreSQL
- **Authentication**: JWT (JSON Web Token)
